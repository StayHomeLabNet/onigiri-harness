# テスト素材

このフォルダは[受け入れテスト手順書](../ACCEPTANCE_TEST_PLAN.md)専用です。人物、組織、日付、コードはすべて架空です。

- `rag`: フォルダごと資料へ追加します。
- `negative`: 1ファイルずつ追加し、エラー処理を確認します。
- `ai-task-workspace`: 一時フォルダへコピーしてAIタスクに使います。
- `decision`: Decision Model Labへ手入力するケースです。
- `acceptance-test-results.csv`: 実施結果の記録用です。

`rag/ignored_sample.csv`は意図的な対象外ファイルです。フォルダ取込後の資料一覧に現れないことを確認してください。

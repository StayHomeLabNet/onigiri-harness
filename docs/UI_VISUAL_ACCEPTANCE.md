# UI Visual Acceptance — Parent Phase 2 / Sub-phase 2.49

更新日: 2026-10-17（Pacific/Auckland）

この手順は、画面幅、表示言語、キーボード操作の違いで、主要な導線が隠れたり操作不能になったりしないことを確認します。既存の総合受入手順は [ACCEPTANCE_TEST_PLAN.md](ACCEPTANCE_TEST_PLAN.md) を使います。

## 準備

```sh
zsh scripts/build-app.sh
open /tmp/onigiri-harness-build/Onigiri.app
```

Apple Foundation Models、LM Studio、Ollamaのいずれか1つで接続済み表示を確認します。資料がある場合と空の場合の両方を確認します。

## チャットのワークスペース

| ID | 操作 | 期待結果 |
| --- | --- | --- |
| UI-01 | 通常幅で、チャット、知識、プロジェクト制作、調査・実験、設定・データを切り替える | 選択中の項目が明確で、目的に対応する操作だけが表示される |
| UI-02 | アプリの幅を最小幅まで狭める | ワークスペース選択がメニューへ切り替わり、項目名と選択状態を確認できる |
| UI-03 | 「知識」で資料追加、資料一覧、検索設定、その他を確認する | 検索、資料操作、詳細機能へ到達でき、ボタンが重ならない |
| UI-04 | 「調査・実験」でWebリサーチ、MCP、Decision Lab、根拠・再現を確認する | すべて到達できる。根拠・再現は根拠がない会話では無効表示でもよい |
| UI-05 | 「設定・データ」でプロファイルとデータ管理を開く | 各サブウインドウを閉じた後、元の会話画面へ戻る |

## プロジェクト制作

| ID | 操作 | 期待結果 |
| --- | --- | --- |
| UI-06 | 「プロジェクト制作」からプロジェクトを開く | 定義、計画、実装、確認、完成の5段階が表示される |
| UI-07 | 5段階を順に切り替える | 各段階に対応する内容だけが表示され、保存ボタンは常に利用できる |
| UI-08 | プロジェクト画面の左右分割バーを動かし、編集領域を狭める | 段階選択がメニューへ切り替わり、ステージ変更が可能 |
| UI-09 | 日本語と英語を切り替えてUI-01〜08を再確認する | 選択項目、説明、ボタンが表示言語に追従し、文字が切れない |

## アクセシビリティとキーボード

| ID | 操作 | 期待結果 |
| --- | --- | --- |
| UI-10 | VoiceOverを有効にしてワークスペース選択と制作ステージ選択へ移動する | 「ワークスペース」「制作ステージ」または英語相当として読み上げられる |
| UI-11 | Tab / Shift-Tabで上部操作を移動し、SpaceまたはReturnで実行する | フォーカスが見え、メニュー、ボタン、テキスト入力を操作できる |

不具合は、画面幅、表示言語、選択中ワークスペース、再現手順、スクリーンショットを添えて記録します。
